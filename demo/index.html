Rétouch

A canvas-based image editor that drops into any web project.
Crop, adjust, filter, annotate — then ship.

$ npm i @retouchjs/core

Try it out

Everything you need, nothing you don't

Ship an image editor in minutes with a clean, composable API.

Drag & Drop

Drop images straight into the editor. Supports multiple files, paste from clipboard, and programmatic file injection via the API.

Crop & Rotate

Freeform crop with draggable handles, preset aspect ratios (1:1, 4:3, 16:9), and rotation. Rule-of-thirds grid overlay included.

Adjustments

Fine-tune brightness, contrast, saturation, and more with real-time preview sliders. All edits are non-destructive and fully reversible.

Gallery Views

Grid, masonry, and list view modes for browsing uploaded images. Batch upload, individual download, and one-click editing from any view.

Export

Export edited images as high-quality Blobs. Works with form uploads, canvas pipelines, or direct downloads. No server round-trip needed.

Zero Config

One import, one line to mount. No framework dependency, no build-step requirement. TypeScript types included out of the box.

Drop in, ship out

Get a full editor running in three lines.

import { Retouch } from '@retouchjs/core'

const editor = new Retouch({
  target: '#editor',
  onDone: (blobs) => {
    // Upload, preview, or download
    console.log(blobs)
  }
})
