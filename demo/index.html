Rétouch

A canvas-based image and video editor that drops into any web project.
Crop, adjust, filter, trim, run on-device ML — then ship.

$ npm i @retouchjs/core

Try it out

Everything you need, nothing you don't

Ship an image and video editor in minutes with a clean, composable API.

Drag & Drop

Drop images and video straight in. Multiple files, an add-more drop target in the gallery, and addFiles() for programmatic injection.

Non-destructive tools

Crop, transform, liquify, curves, HSL, masks, stylize, 14 adjustments and 11 filters. Every edit stays parametric — with undo/redo — until Done bakes it.

Video

Trim on a filmstrip, crop/adjust/filter every frame, 0.25–4× speed, GIF of a range. Re-encoded in the browser via WebCodecs — no upload.

On-device ML

Cutout, 4× upscale, erase, click-to-select, depth bokeh, denoise, face & object detection with @retouchjs/ml. Runs in the browser — no server, no keys.

AI edits

Press ⌘K and say it — “moody and cinematic, crop to a square”. A vision model maps it onto the same edit operations, applied as one undoable step.

Plugins & theming

Register your own feature-group tab in a dozen lines; restyle everything through CSS custom properties. Framework-agnostic, TypeScript types included.

Drop in, ship out

A full editor in one call — ML tools in one more.

import { Retouch } from '@retouchjs/core'
import { installMlTools } from '@retouchjs/ml'

const retouch = new Retouch({
  target: '#editor',
  onDone: (blobs) => {
    // Done in the gallery → every file, edits applied
    upload(blobs)
  }
})

installMlTools(retouch) // optional: cutout, upscale, erase, …
